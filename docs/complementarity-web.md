# Cross-category complementarity: public research view

Visual thesis: a quiet white research canvas with gold and slate for the two models, and purple for aggregation. The ability profile, rather than a decorative hero, is the first visual anchor.

Content plan: select a skill-matched model pair and compare training/test category profiles; separate whole aggregation gain from the increment over global pooling; examine all selected pairs; inspect the oracle-potential/selection-regret decomposition; compare matched, shuffled-label and temporal controls; expose methods and data provenance.

Interaction thesis: selecting a pair links the scatter and the ability profile; a method switch updates the profile's aggregation marker and gain chart together; coverage and source/topic filters update the full cohort with short, reduced-motion-aware transitions. Train and test have one shared BI scale.

The source is the independently audited `specialization_argument_2026-08-31` output. The exporter only copies/restructures its values and checks primary-cohort counts and gains against the original summaries; it does not refit or change the original six aggregation methods. No changes are made to existing market screens.

The interactive pair explorer uses the declared primary event split, with all 1,436 dimension/pair views available before support filters. Other random and temporal views are published as cohort summaries. The initial 50% coverage view is prominently labeled a post-protocol sensitivity; the original 80% view, including its one topic pair and zero matched topic triplets, remains available. The featured Gemini/Grok pair is explicitly posthoc. Missing values are null, not zero, and sparse test categories are distinguished from confirmed preservation of strengths.

Re-export with `python analysis/export_complementarity_site.py --study /path/to/specialization_argument_2026-08-31`. Source hashes and publication hashes are in `site/public/data/complementarity/manifest.json` and `study.json`. Downloads contain model-level derived results and reports; personal local paths and the raw forecast archive are not published.

## Validation

- The publication contract independently checks source-file hashes, all 1,436 primary pair identities, every primary cohort count and method mean, the Gemini/Grok example, undefined versus zero values, and negative temporal evidence.
- Category increments are the audited mean of paired differences, never a difference of separately averaged scores with possibly different missing-value denominators.
- A live browser check confirmed method switching, scatter-to-profile selection, 80% empty matching controls, label controls and negative source temporal increments.
- At a 390-pixel viewport the page has no document overflow. Ability profiles switch between train and test using one fixed BI scale. The page is English-only; keyboard activation and reduced-motion styling are supported.
- The research module and its 6.2 MB data snapshot load only when this page is visited. Existing market screens and method calculations are unchanged.
